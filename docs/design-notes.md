# Design References

Reviewed on 2026-09-18. These projects informed specific design choices; they are not runtime dependencies. Their instruction sets were not bundled, and their teaching effectiveness was not benchmarked here.

| Source | Adaptation |
| --- | --- |
| [learn-codebase](https://github.com/ktaletsk/learn-codebase/blob/main/SKILL.md) | Record actual assistance and revisit relevant gaps in later sessions. Keep direct explanation available instead of requiring questions at every step. |
| [tutor-skills](https://github.com/bevibing/tutor-skills/blob/main/skills/tutor/SKILL.md) | Separate compact context from detailed concept evidence. Preserve independent ability dimensions rather than deriving overall proficiency from quiz accuracy. |
| [tutor-skills quiz rules](https://github.com/bevibing/tutor-skills/blob/main/skills/tutor/references/quiz-rules.md) | Avoid answer cues in descriptions, recommended labels, and preselection. Use open-ended questions when the host UI cannot avoid those cues. |
| [vibe-upskill](https://github.com/bb-cccc/vibe-upskill/blob/main/SKILL.md) | Match the response to the observed kind of gap and use changed conditions to check transfer; do not require an interview-question curriculum. |
| [Anthropic learning-output-style](https://github.com/anthropics/claude-code/blob/main/plugins/learning-output-style/README.md) | Offer meaningful small edits when the learner chooses practice, without inserting unfinished exercises into a delivery task. |

Vibe Code Learning retains its own PR/source-version evidence, Obsidian destination selection, Explain/Test/Feedback boundaries, and preservation of learner-authored records. The default memory budget limits active context, not total stored knowledge. Legacy profiles can retain their original content under a bounded active section; retrieval must remain selective even before that section exists.
